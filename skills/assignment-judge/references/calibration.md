# Calibration: who the professor is grading

The same answer earns different grades in different years. Set the bar from the persona (course, year,
degree), then grade against the instructions; the instructions win when they say more than this file.

## What each stage is expected to show

| Stage | A full-marks answer shows | Typical reasons for lost points |
|---|---|---|
| first year | correct use of the definitions and methods taught; every step shown; the format asked for | skipped steps, missing units, a definition used loosely, not answering the question asked |
| second and third year | a choice of method that is justified; the field's conventions (proof style, IMRaD, IRAC, code quality); limits of the result named | right result with weak justification, conventions ignored, no discussion of assumptions |
| final-year project / seminar | a focused question, use of the literature beyond the course, an argument that holds together, honest limitations | descriptive instead of analytical, sources summarised not compared, overclaiming |
| master's | critical engagement with the literature, methodological rigour, a clear contribution or synthesis | no position of one's own, method not justified, contribution unclear |
| doctoral coursework | publishable-level framing, originality, command of the debate | incremental restatement of known work |

Degree matters inside a course too: a statistics question in a psychology degree is graded on choosing and
interpreting the test; in a statistics degree also on the derivation. Read the discipline pack for the field.

## Grading scales

| System | Scale | Notes |
|---|---|---|
| Israel and many others | 0–100 | the pass mark is set by the institution and sometimes by the course (commonly in the 55–60 range); take it from `COURSE.md` or the syllabus, otherwise ask, otherwise report without pass/fail |
| United States | letter A–F, often with +/- | the percent-to-letter bands differ by course; use the syllabus bands, or report the percent and say the letter depends on the course's bands |
| UK | classes: first ≥ 70, upper second (2:1) 60–69, lower second (2:2) 50–59, third 40–49, fail < 40 | a 75 is a strong first; marks above 80 are rare in essay subjects |
| Germany and similar | 1.0 (best) – 5.0, pass at 4.0 | convert from points only with the course's own table |

Report on the scale the student uses. When converting, say which table the conversion used. The pass mark
is never guessed: no source, no pass/fail line.
