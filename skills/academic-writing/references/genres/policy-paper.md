# Policy paper (נייר מדיניות)

A document for a decision-maker: the problem, the options, the evidence and a recommendation, short enough to be read.

## Structure

- Executive summary (half a page): problem, recommendation, why
- Problem definition with data
- Background and stakeholders
- Options (usually 3), each with costs, benefits, risks
- Evaluation against stated criteria
- Recommendation and implementation steps
- Sources

## What examiners reward

- A clear recommendation
- Options that are real alternatives
- Explicit evaluation criteria
- Data with sources
- Writing for a busy reader: short, headed, plain

## Common mistakes

1. A literature review instead of a decision document
2. Straw-man options set up to lose
3. No costs or feasibility
4. Recommendation buried at the end
5. Academic jargon for a non-academic reader

## Hebrew and English

Write in the submission language. Hebrew papers keep English terms in parentheses at first mention and follow `references/hebrew-academic.md`; English papers by Hebrew speakers get a pass with `references/english-academic.md`.
