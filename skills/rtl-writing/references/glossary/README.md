# Glossary rules

One file per discipline family (the same twelve families as `shared/disciplines/`). Each line is
`- <Hebrew term> (<English term>) — <note>`, which keeps every line Hebrew-first for RTL rendering.

1. First mention in a text: the Hebrew term with the English in parentheses — תהליכון (thread).
2. Afterwards: whichever the course uses. Many courses keep the English term (TLB, PCR, IRAC); follow the course.
3. Identifiers, commands, product names, gene and drug names stay in English and are never translated.
4. A course can override a term in `COURSE.md` (body section "How the lecturer wants answers").
5. `lecture-notes` appends new terms it meets in a course to that course's own glossary file, not to these.
6. Contributions welcome: add terms students actually meet, with a note when Hebrew usage varies.
