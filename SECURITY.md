# Security policy

Please report security issues privately, not in public issues or discussions:
[report a vulnerability](https://github.com/Noam-Marom/academic-students/security/advisories/new)
(GitHub private vulnerability reporting).

In scope: the skills' scripts, the Moodle MCP server (token handling, read-only enforcement) and anything that
could make an assistant using the plugin leak data or act against its user. We aim to reply within a week.
